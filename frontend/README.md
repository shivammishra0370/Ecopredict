# Eco Predict — Day 4 Frontend

## Run

1. Install Node.js LTS if Node is not installed.
2. Open this folder in VS Code.
3. Open VS Code Terminal.
4. Run:

```bash
npm install
npm run dev
```

5. Open the `http://localhost:5173/` address shown in the terminal.

## Build check

```bash
npm run build
```

The current frontend contains the Day 4 UI and demo values. Actual ML values will be connected through FastAPI on Day 6.
