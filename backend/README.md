# Eco Predict — Day 6 Backend

FastAPI backend for connecting the existing Eco Predict Day 1–5 ML artifacts to the React frontend.

## Expected placement

Extract/copy this `backend` folder directly inside your existing `EcoPredict` project:

```text
EcoPredict/
├── backend/
│   ├── app/
│   │   └── main.py
│   ├── requirements.txt
│   └── README.md
├── data/
├── frontend/
├── ml/
├── models/
└── outputs/
```

## Run

Open a terminal in the project:

```bash
cd EcoPredict/backend
```

Install:

```bash
pip install -r requirements.txt
```

Start:

```bash
uvicorn app.main:app --reload
```

Backend:

```text
http://127.0.0.1:8000
```

Interactive API documentation:

```text
http://127.0.0.1:8000/docs
```

Health check:

```text
http://127.0.0.1:8000/health
```

## Main APIs

- `GET /api/stations`
- `GET /api/dashboard`
- `GET /api/analytics`
- `GET /api/forecast?station=gomti_nagar`
- `GET /api/risk`
- `GET /api/inspection-priority`
- `GET /api/policy/library`
- `POST /api/policy/simulate`
- `POST /api/policy/bundle`
- `GET /api/policy/recommend`
- `GET /api/policy/verification`

## Important

The backend reads the ML artifacts generated by the existing notebook. It does not fabricate missing model results.

If `/health` reports missing artifacts, first make sure the Day 5 notebook has been run and these paths exist:

```text
data/processed/lucknow_multi_station.csv

models/multi_station/
├── pm25_forecaster_24h_gomti_nagar.joblib
├── pm25_forecaster_24h_kendriya_vidyalaya.joblib
```
